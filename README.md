#### Sistema de Cadastro e Estoque em C#



Projeto desenvolvido durante meus estudos de C#, com o objetivo de praticar lógica de programação, programação orientada a objetos e controle de versão com Git e GitHub.



O sistema funciona pelo console e permite realizar operações básicas de cadastro de produtos e controle de estoque.



##### Funcionalidades



\- Cadastrar produtos com nome, preço e quantidade.

\- Listar os produtos cadastrados.

\- Consultar a quantidade de produtos cadastrados.

\- Adicionar unidades ao estoque.

\- Remover unidades do estoque, verificando a quantidade disponível.

\- Validar entradas e evitar o cadastro de produtos com nomes duplicados.



##### Tecnologias utilizadas



\- C#

\- .NET 10

\- Git e GitHub



##### Como executar



1\. Tenha o SDK do .NET 10 instalado.

2\. Clone ou baixe este repositório.

3\. Abra um terminal na pasta que contém o arquivo `.csproj`.

4\. Execute o comando `dotnet run`.



##### Observações



Este é um projeto de estudos, ainda sem banco de dados. Os produtos são armazenados em memória e não são mantidos após o encerramento do programa.
